# Techfix Web - v0.0.1

## Descripción
Segunda versión funcional del proyecto **Techfix**, basada en el código recibido inicialmente.

## Trabajo realizado
- Carrito **semi funcional**:
  - Se pueden agregar y quitar productos.
  - Finalización de compra que envía el pedido a WhatsApp.
  - **Sin medios de pago todavía**.
- Sistema de **tickets** para solicitar servicios de la página.
- Conexión a **Supabase y PostgreSQL** para almacenamiento de tickets.

## Próximos pasos
- Añadir medios de pago.
- Panel de administración para tickets y productos.
- Mejoras en UI/UX y optimización general.
